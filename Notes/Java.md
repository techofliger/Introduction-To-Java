# What is Java? ☕

Java is a programming language used to create software, Android apps, web applications, and backend systems.

In simple words, Java is a language through which we give instructions to a computer.

## 1. Your first Java program

```
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

Output:

```
Hello World
```

Easy explanation:

- `class Main` — defines a class named Main.
- `main()` — the starting point of the program.
- `System.out.println()` — displays text on the screen.
- `"Hello World"` — the text we want to display.

## 3. Important features of Java

- Object-oriented: Organizes programs using classes and objects.
- Platform-independent: Java bytecode can run on systems with a compatible Java Virtual Machine (JVM).
- Secure: Provides features that help build secure applications.
- Robust: Includes exception handling and memory management features.
- Popular: Used in many business and enterprise systems.

## 5. How to start learning Java

For your B.Tech CSE and software engineering goal, follow this order:

1. Variables and data types
2. Operators and input/output
3. `if-else` and loops
4. Arrays and strings
5. Methods
6. Object-oriented programming (OOP)
7. Data Structures and Algorithms (DSA)
8. Projects and interview practice
